# NovaAI — AI SaaS Dashboard

Frontend internship Phase 2 — Task 1. Built with React + Vite.

## Run
```bash
npm install
npm run dev
```

## Included
- Landing page, features, pricing, FAQ, contact, responsive navbar/footer
- Login, signup, forgot password and logout UI
- Protected dashboard with sidebar and responsive layout
- AI Chat, Image, Code, Summarizer, Email and Blog tools
- Generate/loading/output/copy/clear interactions
- Searchable/deletable generation history
- Profile and settings pages
- Dark/light mode, notification controls, account settings
- LocalStorage persistence so the demo works without a backend/API key

Demo account: any email + password of 4+ characters.

### Image Generator
The Image Generator now requests a real image from the Pollinations image service and displays it in the result panel with an Open / Save Image action. An internet connection is required for this feature; the other dashboard tools work locally.
